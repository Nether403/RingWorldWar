# Use explicit operational pairs and Alignment-only Dominance

LS-07 represents Spinal pairing as explicit, stable authored topology rather than inferring every pair from geometry. Controlling both members derives a reversible local Spinal Alignment, and only aligned pairs generate Dominance; individual Nodes continue granting Command. This preserves deterministic saves and today's maximum standard-map scoring rate while making territorial connection matter.

We rejected universal antipodal pairing because the complete Spinal Network remains unknown, retained no separate Alignment meter because pair ownership already supplies the authoritative state, and rejected chord accuracy, intelligence, insertion, stabilization, and alternate victory because those pull later launch slices into LS-07.
